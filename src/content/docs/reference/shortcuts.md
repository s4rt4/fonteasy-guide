Keyboard shortcuts save you trips to the menu bar. You do not need to learn them all: start with the five or six you use most (save, undo, the Pen and Select tools, zoom) and the rest will come with time. Every menu also shows the shortcut next to each command, and the [command palette](/power/preferences/#the-command-palette) shows them too, so you can pick them up as you go.

This page lists the shortcuts FontEasy comes with. You can change any of them in **Edit › Keyboard Shortcuts…** (see [Keyboard shortcuts in Preferences](/power/preferences/#keyboard-shortcuts)). If you changed some, the menus show your own shortcuts, not the ones below.

In this reference you will find:

- the menu shortcuts, menu by menu;
- the single-key shortcuts for the drawing tools;
- other keys, such as nudging points and switching masters;
- what the mouse does together with <kbd>Shift</kbd>, <kbd>Alt</kbd> and <kbd>Ctrl</kbd> on the canvas and in the Overview.

## How to read the tables

- `Ctrl+Shift+S` means: hold <kbd>Ctrl</kbd> and <kbd>Shift</kbd>, then press <kbd>S</kbd>.
- A single key such as <kbd>P</kbd> is pressed alone, without <kbd>Ctrl</kbd>, <kbd>Alt</kbd> or <kbd>Shift</kbd>.
- <kbd>=</kbd> and <kbd>-</kbd> are the keys next to <kbd>Backspace</kbd>. The <kbd>+</kbd> key also works where <kbd>=</kbd> is listed, and <kbd>Backspace</kbd> also works for <kbd>Delete</kbd>.
- Shortcuts do nothing while you type in a text field (for example the preview text), and while a dialog is open, so typing letters never switches tools by accident.
- Commands marked *(Pro)* only appear in Pro Mode.

## Tool shortcuts

These single keys choose a tool in the toolbox. They work whenever a font is open and you are not typing in a text field. The [drawing tools chapter](/drawing/drawing-tools/) explains each tool.

| Tool | Key | What it does |
|---|---|---|
| **Select** | <kbd>V</kbd> | Select and move contours, components and anchors. |
| **Node** | <kbd>A</kbd> | Select and edit individual points and handles. |
| **Pen** | <kbd>P</kbd> | Draw Bézier contours point by point. |
| **Add Point** *(Pro)* | <kbd>=</kbd> | Click a segment to add a point. |
| **Delete Point** *(Pro)* | <kbd>-</kbd> | Click a point to remove it, keeping the shape. |
| **Pencil** | <kbd>N</kbd> | Draw freehand; the stroke becomes a smooth contour. |
| **Rectangle** | <kbd>M</kbd> | Drag to draw a rectangle. |
| **Ellipse** | <kbd>L</kbd> | Drag to draw an ellipse. |
| **Polygon** *(Pro)* | <kbd>Shift</kbd>+<kbd>L</kbd> | Drag to draw a regular polygon. |
| **Knife** | <kbd>K</kbd> | Drag across contours to cut them. |
| **Scissors** *(Pro)* | <kbd>C</kbd> | Click a segment to split the contour there. |
| **Rotate** *(Pro)* | <kbd>R</kbd> | Drag to rotate the selection. |
| **Scale** *(Pro)* | <kbd>S</kbd> | Drag to scale the selection. |
| **Measure** *(Pro)* | <kbd>U</kbd> | Measure distances and angles in font units. |
| **Anchor** | <kbd>Shift</kbd>+<kbd>A</kbd> | Click to add an anchor; drag anchors to place accents. |
| **Metrics** | <kbd>Y</kbd> | Drag the sidebearings. |
| **Kerning** | <kbd>J</kbd> | Drag a glyph to kern it against the one before. |
| **Text** | <kbd>T</kbd> | Type text above the canvas; click a glyph of it to edit that glyph. |
| **Hand** | <kbd>H</kbd> | Pan the view. |
| **Zoom** | <kbd>Z</kbd> | Click to zoom in. |

## Other keys

| Where | Keys | What happens |
|---|---|---|
| Glyph editor | <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | Nudge the selected points, components or anchors by 1 unit. |
| Glyph editor | <kbd>Shift</kbd>+arrows | Nudge by 10 units. |
| Glyph editor | hold <kbd>Space</kbd> | Temporary Hand: drag to pan, release to return to your tool. |
| Glyph editor, Pen tool | <kbd>Esc</kbd> or <kbd>Enter</kbd> | Finish the contour you are drawing (it stays open). |
| Glyph editor | <kbd>Esc</kbd> | Deselect everything. |
| Kerning tool | <kbd>←</kbd> <kbd>→</kbd> | Make the pair after the edited glyph 1 unit tighter or looser (<kbd>Shift</kbd>: 10 units). |
| Kerning tool | <kbd>Alt</kbd>+<kbd>←</kbd> <kbd>→</kbd> | The same, as a kerning exception. |
| Fonts with masters | <kbd>Ctrl</kbd>+<kbd>1</kbd> … <kbd>Ctrl</kbd>+<kbd>9</kbd> | Edit master 1 to 9. |
| Overview | arrows | Move to the next glyph; <kbd>Shift</kbd>+arrows adds glyphs to the selection. |
| Overview | <kbd>/</kbd> | Jump to the search field. |
| Overview search field | <kbd>Esc</kbd> | Clear the search. |
| Scripting panel | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Run the script. |
| Command palette | <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>Enter</kbd>, <kbd>Esc</kbd> | Choose a command, run it, close. |
| Shortcut editor | <kbd>Esc</kbd> | Cancel recording a new shortcut. |
| Many dialogs | <kbd>Enter</kbd> | Same as the main button (OK, Create). |
| Sketchboard, Select | <kbd>Delete</kbd> | Delete the selected strokes and words. |

## Mouse actions in the glyph editor

The mouse does more when you hold a modifier key. The tables below are grouped by tool.

### Moving around

| Action | Result |
|---|---|
| Mouse wheel | Scroll (pan) the view. |
| <kbd>Ctrl</kbd>+wheel, or pinch on a touchpad | Zoom in and out around the pointer. |
| Drag with the middle mouse button | Pan the view, whatever tool is chosen. |
| <kbd>Space</kbd>+drag | Pan the view. |
| Zoom tool: click / <kbd>Alt</kbd>+click | Zoom in / zoom out. |
| Zoom tool: drag | Zoom to the rectangle you drew. |

### Select and Node tools

| Action | Result |
|---|---|
| Click a point | Select only that point. |
| <kbd>Shift</kbd>+click a point | Add it to the selection, or remove it if already selected. |
| Click a segment | Select tool: the whole contour. Node tool: the two points at the ends of the segment. |
| Drag in empty space | Draw a selection rectangle; with <kbd>Shift</kbd> it adds to the selection. |
| Drag a point, segment, component or anchor | Move the selection. Points snap to whole units, the metric lines, the advance width and guides. |
| Drag a handle | Change the curve; at a smooth point the handle on the other side turns with it and keeps its length. |
| Drag the advance width line | Change the glyph's width. |
| Double-click a point | Toggle it between corner and smooth (like **Toggle Smooth**). |
| Double-click a segment | Add a point there. |
| Double-click a component | Open the glyph the component shows. |
| Double-click another glyph of the text line | Edit that glyph. |

### Drawing tools

| Tool and action | Result |
|---|---|
| Pen: click | Add a corner point. |
| Pen: drag | Add a point and pull out its handles to make a curve. |
| Pen: click the first point | Close the contour. |
| Rectangle / Ellipse: <kbd>Shift</kbd>+drag | Draw a square / circle. |
| Rotate: <kbd>Shift</kbd>+drag | Rotate in steps of 15°. |
| Scale: <kbd>Shift</kbd>+drag | Scale evenly in both directions. |
| Knife: drag | Cut the contours along the line. |
| Scissors: click a point or segment | Open the contour there. |
| Add Point: click a segment | Insert a point. |
| Delete Point: click a point | Remove it, keeping the shape as well as possible. |
| Anchor: click | Add an anchor (named `top`, `bottom`, … in order). |

### Rulers and guides

| Action | Result |
|---|---|
| Drag from the top or left ruler | Create a horizontal or vertical guide. |
| Drag a guide | Move it. |
| Drag a guide back onto a ruler | Delete it. |

### Metrics, Kerning and Text tools

| Tool and action | Result |
|---|---|
| Metrics: drag near the left or right edge | Change the left sidebearing or the advance width. |
| Kerning: drag a glyph of the text line | Kern it against the glyph before it. |
| Kerning: <kbd>Alt</kbd>+drag | The same, as an exception for these two glyphs only. |
| Metrics, Kerning, Text: click a glyph of the text line | Switch to editing that glyph. |

## Mouse actions in the Overview

| Action | Result |
|---|---|
| Click a glyph | Select only that glyph. |
| <kbd>Ctrl</kbd>+click | Add the glyph to the selection, or remove it. |
| <kbd>Shift</kbd>+click | Select every glyph from the last clicked one to this one. |
| Double-click | Open the glyph in the glyph editor. |
| Right-click | A menu with **Rename Glyph…**, **Duplicate Glyph**, **Copy Names**, **Delete** and mark colours. |
| <kbd>Ctrl</kbd>+wheel | Make the glyph cells bigger or smaller. |

## Summary

- The most useful shortcuts: <kbd>Ctrl</kbd>+<kbd>S</kbd> save, <kbd>Ctrl</kbd>+<kbd>Z</kbd> undo, <kbd>V</kbd> Select, <kbd>A</kbd> Node, <kbd>P</kbd> Pen, <kbd>Ctrl</kbd>+<kbd>0</kbd> fit, <kbd>Space</kbd> pan, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> command palette.
- Tool keys are single letters and only work outside text fields.
- <kbd>Shift</kbd> usually means "more" or "constrained": 10-unit nudges, squares and circles, 15° steps, adding to a selection. <kbd>Alt</kbd> means "the other way" or "exception": zoom out, kerning exceptions.
- Every shortcut can be changed in **Edit › Keyboard Shortcuts…**.

## Try it yourself

1. Open a glyph and draw a rectangle without touching the toolbox: press <kbd>M</kbd>, drag with <kbd>Shift</kbd> held to make a square, press <kbd>A</kbd>, click one corner and press <kbd>Shift</kbd>+<kbd>→</kbd> three times. How far did the point move?
2. Press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> and type `cells`. Which two commands appear, and what are their shortcuts?
