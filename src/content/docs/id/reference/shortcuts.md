title: Shortcut Keyboard
description: Semua shortcut keyboard di FontEasy, dikelompokkan per menu, ditambah tombol alat serta aksi mouse dan tombol pengubah di kanvas dan Ikhtisar.
---

Shortcut keyboard menghemat perjalanan bolak-balik ke bilah menu. Anda tidak perlu menghafal semuanya: mulailah dengan lima atau enam yang paling sering Anda pakai (simpan, batalkan, alat Pena dan Pilih, zoom), dan sisanya akan datang dengan sendirinya. Setiap menu juga menampilkan shortcut di samping perintahnya, begitu pula [palet perintah](/power/preferences/#palet-perintah), jadi Anda bisa mempelajarinya sambil jalan.

Halaman ini memuat shortcut bawaan FontEasy. Anda bisa mengganti semuanya di **Edit › Shortcut Keyboard…** (lihat [Shortcut keyboard di Preferensi](/power/preferences/#shortcut-keyboard)). Kalau Anda sudah mengubah sebagian, menu menampilkan shortcut buatan Anda, bukan yang tercantum di bawah.

Di halaman referensi ini Anda akan menemukan:

- shortcut menu, dikelompokkan per menu;
- shortcut satu tombol untuk alat gambar;
- tombol lain, seperti menggeser titik dan berpindah master;
- fungsi mouse bersama <kbd>Shift</kbd>, <kbd>Alt</kbd>, dan <kbd>Ctrl</kbd> di kanvas dan di Ikhtisar.

## Cara membaca tabel

- `Ctrl+Shift+S` berarti: tahan <kbd>Ctrl</kbd> dan <kbd>Shift</kbd>, lalu tekan <kbd>S</kbd>.
- Satu tombol seperti <kbd>P</kbd> ditekan sendirian, tanpa <kbd>Ctrl</kbd>, <kbd>Alt</kbd>, atau <kbd>Shift</kbd>.
- <kbd>=</kbd> dan <kbd>-</kbd> adalah tombol di samping <kbd>Backspace</kbd>. Tombol <kbd>+</kbd> juga berfungsi di tempat yang tertulis <kbd>=</kbd>, dan <kbd>Backspace</kbd> juga berfungsi sebagai <kbd>Delete</kbd>.
- Shortcut tidak berfungsi selama Anda mengetik di kolom teks (misalnya teks pratinjau) dan selama dialog terbuka, jadi mengetik huruf tidak akan mengganti alat secara tidak sengaja.
- Perintah bertanda *(Pro)* hanya muncul di Mode Pro.

## Shortcut alat

Tombol tunggal berikut memilih alat di kotak alat. Tombol-tombol ini bekerja setiap kali ada font yang terbuka dan Anda tidak sedang mengetik di kolom teks. [Bab alat gambar](/drawing/drawing-tools/) menjelaskan setiap alat.

| Alat | Tombol | Fungsinya |
|---|---|---|
| **Pilih** | <kbd>V</kbd> | Memilih dan memindahkan kontur, komponen, dan anchor. |
| **Node** | <kbd>A</kbd> | Memilih dan mengedit titik serta handle satu per satu. |
| **Pena** | <kbd>P</kbd> | Menggambar kontur Bézier titik demi titik. |
| **Tambah Titik** *(Pro)* | <kbd>=</kbd> | Klik sebuah segmen untuk menambah titik. |
| **Hapus Titik** *(Pro)* | <kbd>-</kbd> | Klik sebuah titik untuk menghapusnya sambil mempertahankan bentuk. |
| **Pensil** | <kbd>N</kbd> | Menggambar bebas; goresannya menjadi kontur yang halus. |
| **Persegi Panjang** | <kbd>M</kbd> | Seret untuk menggambar persegi panjang. |
| **Elips** | <kbd>L</kbd> | Seret untuk menggambar elips. |
| **Poligon** *(Pro)* | <kbd>Shift</kbd>+<kbd>L</kbd> | Seret untuk menggambar poligon beraturan. |
| **Pisau** | <kbd>K</kbd> | Seret melintasi kontur untuk memotongnya. |
| **Gunting** *(Pro)* | <kbd>C</kbd> | Klik sebuah segmen untuk memutus kontur di situ. |
| **Putar** *(Pro)* | <kbd>R</kbd> | Seret untuk memutar pilihan. |
| **Skala** *(Pro)* | <kbd>S</kbd> | Seret untuk mengubah skala pilihan. |
| **Ukur** *(Pro)* | <kbd>U</kbd> | Mengukur jarak dan sudut dalam unit font. |
| **Anchor** | <kbd>Shift</kbd>+<kbd>A</kbd> | Klik untuk menambah anchor; seret anchor untuk menempatkan aksen. |
| **Metrics** | <kbd>Y</kbd> | Seret sidebearing. |
| **Kerning** | <kbd>J</kbd> | Seret sebuah glyph untuk mengatur kerning-nya terhadap glyph sebelumnya. |
| **Teks** | <kbd>T</kbd> | Ketik teks di atas kanvas; klik salah satu glyph-nya untuk mengedit glyph itu. |
| **Tangan** | <kbd>H</kbd> | Menggeser tampilan. |
| **Zoom** | <kbd>Z</kbd> | Klik untuk memperbesar. |

## Tombol lain

| Di mana | Tombol | Yang terjadi |
|---|---|---|
| Editor glyph | <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | Menggeser titik, komponen, atau anchor yang dipilih sejauh 1 unit. |
| Editor glyph | <kbd>Shift</kbd>+panah | Menggeser sejauh 10 unit. |
| Editor glyph | tahan <kbd>Space</kbd> | Tangan sementara: seret untuk menggeser tampilan, lepas untuk kembali ke alat Anda. |
| Editor glyph, alat Pena | <kbd>Esc</kbd> atau <kbd>Enter</kbd> | Mengakhiri kontur yang sedang digambar (kontur tetap terbuka). |
| Editor glyph | <kbd>Esc</kbd> | Membatalkan semua pilihan. |
| Alat Kerning | <kbd>←</kbd> <kbd>→</kbd> | Merapatkan atau melonggarkan pasangan setelah glyph yang diedit sebanyak 1 unit (<kbd>Shift</kbd>: 10 unit). |
| Alat Kerning | <kbd>Alt</kbd>+<kbd>←</kbd> <kbd>→</kbd> | Sama, tetapi sebagai pengecualian kerning. |
| Font dengan beberapa master | <kbd>Ctrl</kbd>+<kbd>1</kbd> … <kbd>Ctrl</kbd>+<kbd>9</kbd> | Mengedit master 1 sampai 9. |
| Ikhtisar | panah | Pindah ke glyph berikutnya; <kbd>Shift</kbd>+panah menambah glyph ke pilihan. |
| Ikhtisar | <kbd>/</kbd> | Lompat ke kolom pencarian. |
| Kolom pencarian Ikhtisar | <kbd>Esc</kbd> | Mengosongkan pencarian. |
| Panel Scripting | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Menjalankan skrip. |
| Palet perintah | <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>Enter</kbd>, <kbd>Esc</kbd> | Memilih perintah, menjalankannya, menutup palet. |
| Editor shortcut | <kbd>Esc</kbd> | Membatalkan perekaman shortcut baru. |
| Banyak dialog | <kbd>Enter</kbd> | Sama dengan tombol utama (OK, Buat). |
| Papan Sketsa, alat Pilih | <kbd>Delete</kbd> | Menghapus goresan dan kata yang dipilih. |

## Aksi mouse di editor glyph

Mouse bisa melakukan lebih banyak hal kalau Anda menahan tombol pengubah. Tabel di bawah dikelompokkan per alat.

### Bergerak di kanvas

| Aksi | Hasil |
|---|---|
| Roda mouse | Menggulir (menggeser) tampilan. |
| <kbd>Ctrl</kbd>+roda, atau cubit di touchpad | Memperbesar dan memperkecil di sekitar penunjuk. |
| Seret dengan tombol tengah mouse | Menggeser tampilan, apa pun alat yang dipilih. |
| <kbd>Space</kbd>+seret | Menggeser tampilan. |
| Alat Zoom: klik / <kbd>Alt</kbd>+klik | Memperbesar / memperkecil. |
| Alat Zoom: seret | Memperbesar ke kotak yang Anda gambar. |

### Alat Pilih dan Node

| Aksi | Hasil |
|---|---|
| Klik sebuah titik | Hanya memilih titik itu. |
| <kbd>Shift</kbd>+klik sebuah titik | Menambahkannya ke pilihan, atau membuangnya kalau sudah terpilih. |
| Klik sebuah segmen | Alat Pilih: seluruh kontur. Alat Node: dua titik di ujung segmen itu. |
| Seret di area kosong | Menggambar kotak pilihan; dengan <kbd>Shift</kbd>, menambah ke pilihan. |
| Seret titik, segmen, komponen, atau anchor | Memindahkan pilihan. Titik menempel (*snap*) ke unit bulat, garis metrics, advance width, dan garis bantu. |
| Seret sebuah handle | Mengubah kurva; di titik smooth, handle di sisi seberangnya ikut berputar dan panjangnya tetap. |
| Seret garis advance width | Mengubah lebar glyph. |
| Klik ganda sebuah titik | Mengganti titik antara sudut dan smooth (seperti **Ubah Smooth**). |
| Klik ganda sebuah segmen | Menambah titik di situ. |
| Klik ganda sebuah komponen | Membuka glyph yang ditampilkan komponen itu. |
| Klik ganda glyph lain di baris teks | Mengedit glyph itu. |

### Alat gambar

| Alat dan aksi | Hasil |
|---|---|
| Pena: klik | Menambah titik sudut. |
| Pena: seret | Menambah titik sekaligus menarik handle-nya untuk membuat kurva. |
| Pena: klik titik pertama | Menutup kontur. |
| Persegi Panjang / Elips: <kbd>Shift</kbd>+seret | Menggambar bujur sangkar / lingkaran. |
| Putar: <kbd>Shift</kbd>+seret | Memutar per 15°. |
| Skala: <kbd>Shift</kbd>+seret | Mengubah skala sama besar ke dua arah. |
| Pisau: seret | Memotong kontur sepanjang garis. |
| Gunting: klik titik atau segmen | Membuka kontur di situ. |
| Tambah Titik: klik sebuah segmen | Menyisipkan titik. |
| Hapus Titik: klik sebuah titik | Menghapusnya sambil mempertahankan bentuk sebaik mungkin. |
| Anchor: klik | Menambah anchor (diberi nama `top`, `bottom`, … berurutan). |

### Penggaris dan garis bantu

| Aksi | Hasil |
|---|---|
| Seret dari penggaris atas atau kiri | Membuat garis bantu mendatar atau tegak. |
| Seret garis bantu | Memindahkannya. |
| Seret garis bantu kembali ke penggaris | Menghapusnya. |

### Alat Metrics, Kerning, dan Teks

| Alat dan aksi | Hasil |
|---|---|
| Metrics: seret dekat tepi kiri atau kanan | Mengubah sidebearing kiri atau advance width. |
| Kerning: seret glyph di baris teks | Mengatur kerning-nya terhadap glyph sebelumnya. |
| Kerning: <kbd>Alt</kbd>+seret | Sama, sebagai pengecualian khusus untuk dua glyph ini. |
| Metrics, Kerning, Teks: klik glyph di baris teks | Beralih mengedit glyph itu. |

## Aksi mouse di Ikhtisar

| Aksi | Hasil |
|---|---|
| Klik sebuah glyph | Hanya memilih glyph itu. |
| <kbd>Ctrl</kbd>+klik | Menambahkan glyph ke pilihan, atau membuangnya. |
| <kbd>Shift</kbd>+klik | Memilih semua glyph dari yang terakhir diklik sampai yang ini. |
| Klik ganda | Membuka glyph di editor glyph. |
| Klik kanan | Menu berisi **Ganti Nama Glyph…**, **Duplikat Glyph**, **Salin Nama**, **Hapus**, dan warna tanda. |
| <kbd>Ctrl</kbd>+roda | Memperbesar atau memperkecil sel glyph. |

## Ringkasan

- Shortcut paling berguna: <kbd>Ctrl</kbd>+<kbd>S</kbd> simpan, <kbd>Ctrl</kbd>+<kbd>Z</kbd> batalkan, <kbd>V</kbd> Pilih, <kbd>A</kbd> Node, <kbd>P</kbd> Pena, <kbd>Ctrl</kbd>+<kbd>0</kbd> muat di jendela, <kbd>Space</kbd> geser, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> palet perintah.
- Tombol alat berupa satu huruf dan hanya bekerja di luar kolom teks.
- <kbd>Shift</kbd> biasanya berarti "lebih" atau "dibatasi": geser 10 unit, bujur sangkar dan lingkaran, langkah 15°, menambah pilihan. <kbd>Alt</kbd> berarti "kebalikannya" atau "pengecualian": memperkecil, pengecualian kerning.
- Setiap shortcut bisa diganti di **Edit › Shortcut Keyboard…**.

## Coba sendiri

1. Buka sebuah glyph dan gambar persegi tanpa menyentuh kotak alat: tekan <kbd>M</kbd>, seret sambil menahan <kbd>Shift</kbd> untuk membuat bujur sangkar, tekan <kbd>A</kbd>, klik salah satu sudutnya, lalu tekan <kbd>Shift</kbd>+<kbd>→</kbd> tiga kali. Seberapa jauh titik itu bergeser?
2. Tekan <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> lalu ketik `sel`. Dua perintah apa yang muncul, dan apa shortcut-nya?
